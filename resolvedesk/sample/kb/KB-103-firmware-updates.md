## Scheduling updates
FleetOS installs firmware during the maintenance window set in Settings > Maintenance. The default window is 01:00 to 04:00 site time. Administrators can postpone an update by up to 14 days.

## Rolling back
If a firmware version causes problems, an administrator can roll back to the previous version within 7 days of the update from Fleet > Firmware > History. After 7 days, contact support to request a rollback.
