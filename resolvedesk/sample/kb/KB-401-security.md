## Suspected account compromise
If you see sign-ins you do not recognise, unexpected changes to robots or users, or a request for credentials that claims to come from Northwind, treat it as a security incident. An administrator should immediately reset passwords for affected users and revoke active sessions from Settings > Security. Northwind's security team handles every report directly; support agents do not resolve security incidents themselves.
